# Avani's Home Bakes website

A responsive five-page home bakery website in a pastel pink and cream theme.

## Pages
- `index.html` — Home
- `menu.html` — Menu
- `about.html` — Our Story
- `gallery.html` — Gallery
- `contact.html` — Contact and WhatsApp enquiry form

## Before publishing
1. Open `js/main.js`.
2. Replace `91XXXXXXXXXX` with the bakery's WhatsApp number, including country code and digits only. Example format: `919876543210`.
3. Replace the sample gallery/food photos with your own product photos.
4. Update menu items, location, pricing, and business details to match the bakery.

## Preview
Open `index.html` in a browser. Internet access is needed for the Google Fonts and remote sample photos.

The WhatsApp form prepares a message and opens WhatsApp. The customer reviews and sends it there; the website does not send messages automatically.
